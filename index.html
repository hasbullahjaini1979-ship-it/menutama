Statistik Kunjungan

Setiap kali pengunjung membuka salah satu menu aplikasi (termasuk menu uji coba dan Website Sekolah), kunjungan dicatat otomatis ke Google Sheet melalui Google Apps Script. Sambungkan URL Web App di bawah ini untuk mengaktifkan dan melihat statistiknya.

Salin URL ini setelah men-Deploy Apps Script sebagai Web App (lihat panduan & kode di bawah).

⚙️
Panduan Pemasangan (Google Apps Script)
  1. Buka sheets.google.com, buat Spreadsheet baru (misal beri nama "Statistik SIMARA").
  2. Buka menu Ekstensi → Apps Script.
  3. Hapus kode contoh, lalu tempel kode di bawah ini (tombol "Salin Kode").
  4. Klik Deploy → New deployment, pilih tipe Web app.
  5. Pada "Execute as" pilih Me, pada "Who has access" pilih Anyone, lalu klik Deploy.
  6. Salin URL Web App yang muncul, tempel ke kolom URL di atas, lalu klik "Simpan & Muat Statistik".
  7. Sheet "Rekap Kunjungan" dan "Log Kunjungan" akan otomatis terbentuk di spreadsheet Anda.
